## Datatype decisions (drive the application obligations)
| Oracle | PostgreSQL | Note |
|---|---|---|
| `NUMBER(19,0)` identity PK | `bigint GENERATED BY DEFAULT AS IDENTITY (START WITH 101)` | START preserved per table (`password_reset_tokens` 1) |
| `NUMBER(10,0)` | `bigint` | exceeds int32 |
| `NUMBER(38,2)` | `numeric(38,2)` | |
| `NUMBER(1,0)` flags | `smallint` + `CHECK (x IN (0,1))` | **not** boolean — data copied verbatim; app `Boolean` fields need `@JdbcTypeCode(SMALLINT)` |
| `DATE` | `timestamp(0)` | carries time; app `LocalDate` fields need `@JdbcTypeCode(TIMESTAMP)` |
| `BLOB` | `bytea` | app `@Lob byte[]` → `@JdbcTypeCode(VARBINARY)` |
| `VARCHAR2(n CHAR)` | `varchar(n)` | |

## Objects
- 14 tables: 14/14 applied first pass. `SYS_C*` PK indexes and the `SYS_IL…` LOB index not re-created.
  ORDERS has **no** FK in the source — none invented (FK guard: `source_fk_count` 0).
- `BOOKS_TEXT_IDX` → `CREATE INDEX books_text_idx … USING gin (to_tsvector('english', coalesce(search_text,'')))`.
- `TRG_BOOK_SEARCH_TEXT` → trigger function + `BEFORE INSERT OR UPDATE OF title, author, isbn` trigger,
  `RETURN NEW`; every `||` operand wrapped in `coalesce` (Oracle treats NULL as '').
- 15 code units (packages spec+body as one unit): 15/15 applied first pass.
  - `SELECT … INTO STRICT` where Oracle relied on `NO_DATA_FOUND` handlers.
  - `COMMIT` removed from `archive_old_orders`, `clear_shopping_cart`, `process_customer_offer`, `set_book_featured`.
  - `DELETE FROM (subquery)` → direct `DELETE`; `SQL%ROWCOUNT` → `GET DIAGNOSTICS`; `DBMS_OUTPUT` → `RAISE NOTICE`.
  - `RAISE_APPLICATION_ERROR(-20001/-20002)` → `ERRCODE 'U0001'/'U0002'` (app error-code contract).
  - `reporting_pkg_get_top_books` → `RETURNS TABLE (book_id bigint, title varchar, total_sold numeric, revenue numeric)`
    — types taken from the converted columns/aggregates (the declared-type hazard from the last workshop).
  - `validation_pkg_is_valid_isbn`: `regexp_replace(…, 'g')` (Oracle replaces all matches).
  - `book_pkg_get_avg_price` keeps `listings.price%TYPE` (numeric(38,2)) so AVG is rounded to 2 dp as in Oracle.
